DocBot 2026

BSc Undergrad Thesis · ML Research · Hierarchical Classification

Supervised by Mrs. Manoara Begum, Mrs. Taofica Amrine — Assistant Professors, Dept of CSE, PCIU

An Explainable Framework for Preliminary Disease Prediction Using NLP Symptom Extraction and Hierarchical Machine Learning

Built a 771-disease taxonomy spanning 14 categories and 8 super-categories using Davidson's clinical grouping framework, then benchmarked four classification architectures against it — flat, 2-stage hierarchical, 3-stage hierarchical, and an adaptive hierarchical transfer approach. The 3-stage cascade is framed as the clinically interpretable option: explainability-first over raw accuracy.

Separately building a clinical validation layer: cross-referencing 5,372 disease–symptom pairs against two medical reference texts to ground the taxonomy in real clinical presentation categories and red-flag severity.

  • Four classification architectures benchmarked head-to-head — flat, 2-stage, 3-stage hierarchical, and adaptive transfer.
  • 771-disease / 377-symptom hierarchical taxonomy built on Davidson's clinical grouping framework.
  • Explainability-first framing using SHAP / TreeSHAP — interpretability over raw accuracy.
  • Two-textbook clinical cross-validation: 5,372 disease–symptom pairs verified against medical references.

YOLOv8-Based Safety Helmet Detection

Computer Vision

A real-time YOLOv8 computer vision system for construction-site PPE compliance, designed to detect safety violations quickly while balancing detection accuracy with deployment speed.

Supervised by Mrs. Manoara Begum

Association with Md. Shahriar Hossen, Payel Chowdhury, Jannatun Nur

  • Data pipeline — ~5,000 construction-site images from the Kaggle "Hard Hat Detection" dataset, with Pascal VOC annotations converted to YOLO format and augmentation using Mosaic, Mixup, Copy-Paste, and HSV transformations.
  • Model comparison — benchmarked YOLOv8s for speed against YOLOv8m for precision, training both for 50 epochs with AdamW, cosine-annealing LR scheduling, mixed precision, and early stopping.
  • Helmet-class performance — YOLOv8s reached 96.4% mAP@50 / 94.5% precision; YOLOv8m reached 97.1% mAP@50 / 94.7% precision.
  • Deployment choice — YOLOv8s was selected for production because it maintains >94% precision at 119 FPS on a Tesla T4 while using a smaller footprint (11.2M vs 25.9M params), making it practical for edge devices and live surveillance.
